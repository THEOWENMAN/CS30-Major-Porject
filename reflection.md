# Major Project Reflection

## What advice would I give myself if I was to start a project like this again?
If I were to start this project again, I would begin with a thorough design of the project, drawing out my ideas and maps to get a visual of my project and writing out pseudo code to improve my understanding of the logic and readability of the algorithm because in this project I had gone straight into coding often not knowing where the most efficient place to start and what additional pieces of codes I needed, I would jump from coding the movement to coding the HP functions and more. Therefore errors would sometimes appear, and I would have to reread the entire code and console.log sections to find the bugs. Another piece of advice is to find a couple of new websites or YouTube tutorials to perceive a different perspective on how to write my code. Last, I should have created a test JS file for coding new functions, which would allow me to test out the concept and efficiently detect errors.
